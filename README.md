# ElectronDevelopment

Builds and reviews secure Electron applications with isolated renderer processes, validated IPC, safe preload APIs, packaging, and updates.

- Practical guidance for electron development workflows.
- A consistent process for reviewing requirements, making decisions, and validating results.
- Use `SKILL.md` as the primary reference.
